# Flow Yoga & Pilates Studio — Lab Work 9

## Files
- `index.html` — semantic HTML structure and booking form
- `style.css` — responsive styling, CSS Grid/Flexbox, light/dark theme styles
- `images/` — folder reserved for exported image assets (this design uses CSS illustration)

## Run locally
Open `index.html` in a browser, or use the Live Server extension in Visual Studio Code.

## Before submitting
1. Make Figma frames at 1440px (Desktop) and 390px (Mobile), with 12 and 4 columns.
2. Compare both designs against the website and adjust if your instructor requires exact visual matching.
3. Publish the files to a public GitHub repository.
4. Enable Settings → Pages → Deploy from branch → `main` → `/ (root)`.
5. Confirm the published link works.

## Important
This is a coursework demo. The prices and timetable are sample content; the form does not send bookings to a real studio. The dark-mode control works locally.
